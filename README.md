# NeetCode Solutions — @iammoein

My solutions to coding interview problems from [NeetCode](https://neetcode.io/), primarily written in **TypeScript**.

This repository is automatically synced with my NeetCode submissions through GitHub Sync.

[NeetCode](https://neetcode.io/) is a coding interview preparation platform with a curated collection of algorithm and data structure problems, explanations, and solutions.

I'm using this repository to:

* Improve problem-solving skills
* Strengthen my **TypeScript** knowledge
* Keep track of my solved problems

## 🗂️ Repository Structure

Solutions are organized by topic and problem:

```text
<topic>/
└── <problem>/
    ├── submission-0.ts
    ├── submission-1.ts
    └── ...
```

For example:

```text
Arrays & Hashing/
├── two-sum/
│   └── submission-0.ts
├── valid-anagram/
│   └── submission-0.ts
└── contains-duplicate/
    └── submission-0.ts
```

Each `submission-X` represents a separate submission for that problem.

## 🔄 GitHub Sync

This repository is synchronized with my [NeetCode](https://neetcode.io/) account.

By default, GitHub Sync can be configured to:

* Automatically commit new submissions
* Sync only accepted solutions
* Sync all submissions
* Bulk sync previous submissions

Sync settings can be managed from the GitHub settings section of NeetCode.
